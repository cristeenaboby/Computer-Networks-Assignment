# Assignment
ASSIGNMENT-01

## Title
How the Internet Delivers a Web Page

## Objective
To understand how a web page is delivered over the Internet by studying the TCP/IP protocol stack, DNS, HTTP, TCP, client-server architecture, cookies, and comparing HTTP with FTP using Amazon as an example. 

## Solution
The assignment explains how www.amazon.com is accessed through the Internet. It describes how DNS converts the domain name into an IP address, how HTTP sends requests and receives responses, how TCP ensures reliable communication, the functions of each TCP/IP layer, the client-server architecture, the differences between HTTP and FTP, and how cookies improve the user experience.

## Output
The study demonstrates the complete communication process involved in loading the Amazon web page. It shows how different Internet protocols and TCP/IP layers work together to provide secure, reliable, and efficient web communication. 

## Conclusion
This assignment provides a clear understanding of how Internet communication takes place while accessing Amazon. It highlights the importance of DNS, HTTP, TCP/IP, cookies, and the client-server model in delivering fast, reliable, and user-friendly web services.
